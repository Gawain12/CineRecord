🔐 账户认证 (手动配置)

若应用部署在无桌面环境的 Linux 服务器等设备上，自动获取功能将无法使用，请在此手动填入 Cookie。

💡 桌面端外无法唤起登录窗口？请按照以下步骤获取：
  1. 在电脑浏览器中新建无痕窗口，打开目标网站并手动登录账号。
  2. 按 F12 打开开发者工具，切换到 Network (网络) 标签并刷新。
  3. 点击列表中第一项（主域），在右侧找到 Request Headers (请求标头)。
  4. 找到 cookie: 字段，复制其后的所有内容，粘贴至下方对应的输入框即可。
☁️ CookieCloud 未同步

从 CookieCloud 手动同步浏览器里的登录态到本地配置，不会覆盖用户 ID。

教程与项目： GitHub / Juejin 教程 。建议优先使用自建 CookieCloud 服务。
